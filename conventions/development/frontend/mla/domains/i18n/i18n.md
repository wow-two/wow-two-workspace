# I18n

*Last updated: 2026-08-19*

> The locale a subtree reads, the message resolver bound to it, and the formatters that locale drives.
> Purpose — a locale switch has to re-evaluate every descendant, and formatter construction is paid once.
> Use case — formatting embedded text, overriding an SDK-authored message, or scoping a locale to a subtree.

## The contract

- must expose the active locale as a reactive value — provision alone does not re-evaluate descendants.
- must resolve a message as consumer override, then SDK-authored fallback, then the raw key.
- must accept a resolver as either a key-to-template dictionary or a callback, so ICU stays bring-your-own.
- must interpolate braced tokens from the supplied variables, leaving an unknown token untouched.
- must keep the resolver a plain function reading messages at call time, so its identity never changes.
- must work with no provider mounted, standing in the default locale and fallback-only messages.
- must read the navigator locale lazily, so a render that never asks never touches it.
- must fall back to a fixed default locale when there is no navigator.
- must cache formatter instances by locale and options — construction is the expensive part.
- must rebuild the formatter set only when the active locale changes.
- must render no element from the provider; the slot passes straight through.
- must let a component own a locale without a wrapper element.

## Providers

| Provider | Implements | Reach for it when |
|---|---|---|
| `Intl` | number, currency, percent, date, time, relative, list, plural | every formatting call |
| dictionary messages | a key-to-template record read by the resolver | a small, static override set |
| callback messages | a key-and-variables function | an ICU or catalogue library owns the lookup |

---

```txt
✅ formatters.value.currency(1234, 'USD')       cached per locale and options
✅ t('table.empty', undefined, 'No rows')       the fallback stands in unoverridden
❌ new Intl.NumberFormat(navigator.language)    a fresh instance, and a global read eagerly
```
